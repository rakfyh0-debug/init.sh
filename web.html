Créer sa propre plateforme web

Comprends comment une application comme RéviBF fonctionne vraiment, puis construis la tienne : de la première page HTML jusqu'à ton propre projet en ligne.

Commencer cette formation

Pour qui ?

  • Tu as vu RéviBF et tu te demandes comment c'est construit
  • Tu veux créer un outil utile, pas juste suivre des exercices abstraits
  • Tu es autodidacte et tu veux un projet concret à montrer
  • Tu ne connais rien au code, ou presque, et tu veux partir de zéro

Ce que tu vas apprendre

Six modules, dans l'ordre, avec RéviBF comme exemple concret du début à la fin.

01

Comprendre une plateforme comme RéviBF

Analyse de la structure, différence entre interface, données et interactions, ce qui est stocké localement.

02

Bases HTML / CSS / JavaScript

Structure d'une page, mise en forme, rendre une page interactive, manipulation simple du DOM.

03

Créer un système de quiz

Stocker des questions, les afficher une par une, gérer le score, sauvegarder la progression, donner du feedback.

04

Design et expérience mobile

Rendre l'application claire et belle, responsive, améliorer l'expérience utilisateur.

05

Mise en ligne avec GitHub Pages

Compte GitHub, mettre le code en ligne, activer GitHub Pages, obtenir un lien public.

06

Projet final guidé

Choisir un sujet et construire sa propre petite plateforme de A à Z, jusqu'à la mise en ligne.

Ce que tu sauras faire à la fin

  • Comprendre l'architecture d'une application web comme RéviBF
  • Écrire du HTML, du CSS et du JavaScript de base sans copier-coller à l'aveugle
  • Construire un système de quiz ou de contenu interactif fonctionnel
  • Rendre une application utilisable confortablement sur mobile
  • Mettre un projet en ligne gratuitement, avec un lien à partager
  • Avoir ta propre application web personnelle, en ligne, avec le code sur GitHub

Comment ça se passe

La progression est linéaire : tu ne peux pas sauter un module. Chaque module se termine par un bout de code fonctionnel ; une fois fait, tu cliques sur "J'ai terminé ce module" et le suivant se débloque.

Tu peux suivre cette formation en parallèle de Linux Pratique — les deux progressions sont indépendantes.
